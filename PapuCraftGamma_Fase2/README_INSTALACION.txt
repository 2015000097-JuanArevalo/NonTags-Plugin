PAPUCRAFT GAMMA - FASE 2
========================

Archivos incluidos:
- PapuCraftNametags-source/ : código fuente del bridge de nametags.
- DeluxeMenus/papucraft_menu.yml : menú principal /menu.
- Snippets/tab-apex.yml : ejemplo de TAB con ApexClan.
- Snippets/luckperms-fase2.txt : permisos nuevos.
- Snippets/economyshopgui-policy.yml : patrón buy-only para /shop.

IMPORTANTE:
- El bridge se entrega como código fuente, no como JAR compilado.
- Para obtener el JAR usa el workflow de GitHub Actions incluido en el proyecto.
- Antes de reemplazar hClans, apaga el servidor y guarda backup de plugins/hClans.
